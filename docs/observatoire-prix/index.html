LA MÉTHODE

Rendre la collecte vérifiable.

Le panier porte sur dix références de chocolat et pâtisserie d’une même marque. Neuf formats sont de 1 kg ; le Mycryo est au format 550 g. Les identifiants GTIN n’ont pas été vérifiés.

Les premières lectures et le complément CuisineAddict ont eu lieu le même jour. Ce complément améliore la couverture de R1 ; il ne constitue pas une deuxième observation dans le temps.

Lire la méthode détaillée Markdown

  1. Conserver la référence et son format

    Relier chaque observation au produit recherché et à sa source. Une variante ou un autre conditionnement reste une différence à qualifier.

  2. Qualifier le montant affiché

    Distinguer prix courant et prix barré ; noter la base fiscale seulement lorsqu’elle est prouvée. Les frais de livraison et remises négociées sont hors périmètre.

  3. Conserver les inconnus

    Les conditions Cerf Dellier évoquent HT et TTC sans qualifier les montants extraits. Les dix bases restent donc inconnues, sans conversion supposée.

  4. Reproduire les effectifs publics

    Le CSV de couverture et le script joint permettent de retrouver les trente relevés présents et les vingt qualifications fiscales connues.

CE QUE L’ON PEUT CONCLURE

Un pilote de faisabilité, avec ses limites visibles.

Une date ne donne pas une évolution

R1 documente une journée. Mesurer une hausse ou une baisse demande une nouvelle observation réelle, sur les mêmes références et des bases comparables.

Un panier ciblé

Dix références d’une marque chez trois détaillants ne représentent pas les achats des restaurants français. Aucun classement de fournisseurs n’est établi.

Des fichiers publics limités à la couverture

Les montants bruts des catalogues ne sont pas diffusés. Le jeu public contient les références, les dates, la présence d’un prix, sa qualification et les liens de provenance. Il permet de reproduire des effectifs, pas une analyse de niveaux de prix.

Les relevés suivants sont prévus les 10 et 24 novembre, puis le 8 décembre 2026. Ces collectes futures restent à effectuer ; elles ne sont pas comptées dans les résultats de ce pilote.

Reproduire les résultats sur votre ordinateur

Décompressez le dossier, puis lancez ces deux commandes dans son répertoire avec Python 3.12 ou une version compatible :

python -m unittest -v test_couverture.py
python analyse_couverture.py couverture-r1.csv

Le résultat doit correspondre à resultats-couverture.json. Les observations de couverture sont conservées telles qu’elles ont été documentées ; aucune donnée client n’est nécessaire.
